# 将活动网页接入原小程序

这里是待接入的宿主页文件。尚未获得 1.0.5 源码，因此没有改动、覆盖或上传任何现有小程序。

1. 将 `miniprogram/pages/bubble-h5/` 复制到 1.0.5 的小程序源码目录下，并在其 `app.json` 的 `pages` 数组追加 `pages/bubble-h5/index`。如果既有项目使用编译框架，应由维护者按框架的路由方式注册。
2. 把该页 `index.js` 中的 `H5_URL` 改为已部署的固定 HTTPS 网页目录地址，保留末尾 `/`。不能把用户传入的 `url` 参数直接拼接为跳转地址。
3. 在原首页增加活动入口，点击执行 `wx.navigateTo({url:'/pages/bubble-h5/index'})`。
4. 在同一个小程序账号的业务域名配置中校验网页域名；网页后端 CORS 的 `H5_ALLOWED_ORIGINS` 必须精确填写该 HTTPS Origin。接口域名使用 HTTPS。H5 内图片/跳转域名的可用性需真机验证。
5. 宿主页调用原生 `wx.login` 取得临时 code，用 `#/home?wx_code=...&return_route=...` 传入 H5。网页读完后立即删除片段中的 code，通过 `/session` 换取只保存在内存的 15 分钟令牌。AppSecret 和签名密钥始终只保存在新云函数环境变量中。
6. 会话过期或刷新 H5 后，返回小程序入口重新进入。网页若接入官方微信 JS SDK，可调用 `wx.miniProgram.redirectTo({url:'/pages/bubble-h5/index?return_route=%2Fprize'})` 重新登录；只能返回预置 `/home`、`/prize`、`/rules`、`/staff` 页面。未接入 SDK 时提示用户返回并重新打开，不伪造登录。
7. 分享只使用固定的原生页路径，不能分享含 `wx_code`、token 或员工核销码的网页地址。活动小程序码需在原生宿主页正式发布后生成。

需要相同 AppID `wx3cfec968f30fb6c1` 才能通过原有 OpenID 和 `campaignId:openid` 算法继续关联中奖记录。不同 AppID 的 code 不可混用。

浏览器不能直接使用原生小程序的 `wx.cloud.callFunction`、`wx.scanCode`、`wx.saveImageToPhotosAlbum`。正式 H5 通过鉴权接口调用业务，核销输入支持手工粘贴/扫码枪；摄像头扫描需要额外的设备能力验证。活动码由服务器转换为 HTTPS 临时图像地址供展示。

## 本次核实依据与范围

- [CloudBase 官方：在微信小程序中接入用户认证](https://docs.cloudbase.net/recipes/add-auth-wechat-miniprogram)：临时 code 由原生 `wx.login` 获取，不能缓存复用；官方检索结果注明有效期 5 分钟且只能交换一次。
- [CloudBase 官方：通过 HTTP 访问云函数](https://docs.cloudbase.net/service/access-cloud-function)：按 `event.httpMethod/path/headers/body` 接收 HTTP 请求并返回 `statusCode/headers/body`，网关按此事件格式实现。
- [微信官方：code2Session](https://developers.weixin.qq.com/miniprogram/dev/OpenApiDoc/user-login/code2Session.html) 和 [web-view](https://developers.weixin.qq.com/miniprogram/dev/component/web-view.html) 是上线核对入口；本次检索工具无法打开这两个页面，未声称已完整读取其当前规则。业务域名配置、备案要求与页面权限最终以账号后台及最新官方文档为准。

本次没有进行真实微信登录、线上抽奖、核销、云端部署或小程序上传。只有隔离测试和本地源码接入文件。
