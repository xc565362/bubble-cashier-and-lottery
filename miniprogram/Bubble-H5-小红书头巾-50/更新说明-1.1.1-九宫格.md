# 关注抽头巾 · 九宫格版

2026-10-08，H5 工程版本 1.1.1。

首页改为九宫格：外围四个角是奖品，四条边是“谢谢惠顾”，中央是抽奖按钮。沿外围顺时针高亮，减速后停在与后台结果一致的格子，停留 300 毫秒再展示结果。

继续使用黄橘色多色块头巾示意图和轻浅配色。收银系统配置的奖品、图片、概率、数量仍自动同步；默认奖品为魔术头巾，200 份，中奖概率 50%。格子的数量不参与计算中奖概率。

中奖后仍展示原来的领取凭证，到收银系统扫描，使用“零元结算”完成核销。已参与用户只能查看保存的结果。此版只更新 H5，无须重新安装收银软件。

验证：`npm test` 共 94 项通过。新增转圈顺序、中奖/未中奖落格、停格等待、重复点击、隐藏页面取消、错误响应、计时器清理和减少动态效果等验证。浏览器检查了动画及结果，并通过独立 iframe 检查 320 与 390 像素宽度布局。

正式 H5 文件在 `dist`，运行 `npm run build` 可重新生成。`public/runtime-config.js` 仍保留待配置状态，本次只更新本地源码、构建和演示，未部署云端。演示活动日期仅用于隔离测试，不是正式活动时间。
