# 山野有约视觉规范

## Direction

在明亮的赛事展位旁，参与者单手打开手机看清奖品并完成抽奖。采用白底和近白水蓝、墨蓝文字、少量橙色按钮的克制配色，让商品与操作成为重点。

参考的是原 Bubble 抽奖页面的字标、领取券结构和手机节奏；新页面取消饱和橙色大底、九宫格和强促销装饰。单品插画、两行中文标题与少量路线线条构成识别。

## Color roles

- `--surface`: 纯白，正文与核销码底色。
- `--sky`: 清浅水蓝，首屏和奖品说明背景。
- `--ink`: 墨蓝，用于标题和主体文字。
- `--muted`: 较深蓝灰，用于辅助文案，保持可读性。
- `--accent`: 降低明度的橙色，承接 Bubble 既有品牌；仅用于主要按钮和少量状态强调。
- `--line`: 浅冷灰蓝，用于区分必要的边界，不作为文本颜色。

## Typography

保留既有系统中文字体栈，避免新增字体下载影响现场网络。Bubble 字标延续 Arial 黑体斜体；正文使用 PingFang SC / Microsoft YaHei，标题与正文靠字号、字重和留白分层。中文主标题 34–44 px、正文 14–16 px；不使用装饰性衬线或大面积英文字母。

## Layout

手机主体最大 480 px。16–24 px 横向留白，首屏单品图为主角；50% 是与奖品相邻的小印记，不构成独立数据看板。主要按钮充满内容宽度。三个步骤确为参与流程，允许用序号表达顺序。

奖品凭证是唯一强调纸券结构的容器。规则采用列表，流程采用开放排版；不使用重复卡片网格。工作人员表单保持明确输入框和完整动作文案。

## Imagery

`public/assets/scarf.svg` 是以黄橘色为主的多色块管状魔术头巾的示意插画。用布面褶皱、开口与细线表现形态，非实际商品照片。正式对外展示前应替换成确认后的商品图，并同步移除示意提醒。

## Interaction and accessibility

- 按钮、页签与摘要控件至少 44 px 高；输入字号 16 px，减少手机聚焦缩放。
- `:focus-visible` 使用深蓝实线外框；有边界的小控件内部展示焦点。
- 抽奖时仅商品图轻微摆动，单次周期 0.7 秒；减少动态偏好下禁用动画和位移动效。
- 核销码保持纯白背景、清晰静区和整数像素呈现，不为装饰裁切二维码。
- 弹窗使用原生 dialog；底部导航与提示使用明确 z-index 层级；保留安全区。
- 320 px 使用更紧凑的字标、主标题和横向留白，长核销码与链接可换行。

## Implementation contract

`.hero` 自带横向留白；主要内容区块可直接放在 `.screen` 内。若采用 `.content` 包裹区块，直接子级的水平 margin 会归零，以免重复留白。视觉验证由主任务的浏览器检查完成，本文不把未做的设备检查记为通过。
