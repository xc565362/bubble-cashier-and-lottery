# 收银系统0.7.4使用说明

本版仅更新实物奖品商品识别及显示名称，共用网页、Windows和Mac源码逻辑，不改变奖池、历史中奖或支付规则。

## 实物对应关系

| 奖品商品名称 | 货品编码 |
| --- | --- |
| 轻量化运动腰包（海雾蓝） | BB240011 |
| 户外棒球帽（砾石灰） | BB250005 |
| 户外渔夫帽（晨雾蓝） | BB250003 |
| 超大号购物袋 | 可留空，按完整商品名识别 |

前三种商品按货品编码或条码精确匹配，不要求69开头。购物袋兼容旧名称“超大编织袋”；这两个名称合计只能对应一个商品。如果存在两个候选，系统会阻止绑定，不能把“礼品袋”默认当成中奖购物袋。

在商品管理中维护真实商品和实际库存，再进入“券管理 → 实物商品绑定”确认。中奖顾客出示的是小程序中奖码，袋子本身无需另印条码。当前实际库存必须大于0才能绑定和发货，不会用抽奖名额代替实际库存。

后续库存和售价可以继续调整；商品名称、编码、条码变化，或删除后重建商品，需要重新核对绑定。缺失商品、无库存、重复编码或名称都会阻止错误出库。

## 本次没有改动

- 用户经营备份只读核对，没有恢复覆盖商品、订单、图片或库存。
- 原正式收钱吧配置、原券中心、原发券凭证及历史中奖记录保留。
- 实物领奖尚未切换到收银端，待实际商品维护、绑定、历史实物迁移和真机验收后再启用。不能只看到新版页面就发放奖品。

## 更新方式

- 网页：先完成未决收退款，关闭原启动窗口，再双击原“启动收银网页版”，继续使用原浏览器和 `http://localhost:5173/`，不要清缓存或换端口。
- Windows：本版软件在发行目录windows中，仍需使用原Windows用户。旧快捷方式不会自动改为新版；网页和桌面经营数据并非自动共享，正式收钱吧及券连接须在目标实例核对后使用。
- Mac：发行文件为完整源码构建包，不是已生成的DMG。在Mac按原构建流程执行build-mac.command；未在Mac真机验证。换机时先导出经营备份及加密收钱吧配置，再迁移并核对券中心和商品绑定。
