# 收银系统 0.7.9 使用说明

更新日期：2026-09-29。本次新增流水按字段查询，保留 0.7.8 的售卖与赠送共用商品、库存、收钱吧及抽奖联动功能。

## 查询流水

1. 进入底部“流水”。默认查看今天；查询历史记录可选日期，或点击“全部日期”。
2. 在“查询字段”中选择要查的内容，再填写“查询内容”。未选字段不能输入和查询。
3. 点击“查询”，或在输入框按回车。下方显示已应用的日期和查询条件。
4. 点击“重置”清除字段与关键词，保留日期；“回到今天”和“全部日期”只改变日期范围。
5. 点击流水区域的“导出匹配订单明细”，导出当前结果。顶部下载图标仍为导出全部流水，不受筛选影响。

可查 45 个字段：全部 33 个原有流水导出字段，以及订单当前状态、订单净额、订单原金额、订单总优惠、订单原实收、变更次数、收款环境、实物奖品核销状态、退换货原因、资金类型、支付单号、渠道原支付或退款金额。

- 名称、条码、编码、流水号等文字字段支持部分内容匹配，不区分英文字母大小写，忽略首尾空格。
- 金额用元填写，数量用数字填写，均按数值精确匹配。例如 120 和 120.00 等价；输入 20 不会匹配 120。退款明细可查负数。
- 时间支持日期或部分时间，例如 2026-09-29、2026-09-29 10:00。页面日期筛选按当前设备本地日期计算。
- 一次查询一个字段，可以叠加日期条件。修改查询字段会清空待输入内容；再次点击“查询”前，旧结果仍保留并显示“尚未应用”，此时流水区域的导出按钮禁用，避免导错。
- 查询的是当前电脑保存的流水，不会查询另一台电脑或云端未同步的订单。

示例：选“货品编码”，填 BB240011，可查含该商品的订单；选“收钱吧流水号”查支付或退款编号；选“退换货原因”查“尺码”；选“订单当前状态”查“已全额退款”。

## 金额与导出口径

查询按完整订单展示。只要选定日期范围内的一条商品或资金明细符合条件，该订单就会出现；不是把商品行单独拆成新订单。订单卡片继续显示原交易和完整退换货历史。

汇总是“匹配订单”在所选日期范围内的收款、退款和净收入，不是某个商品的销量统计。导出保留这些订单在该日期范围内的全部明细，包括优惠券、赠品、退回与换出商品，便于对账。

退款、补款使用实际资金发生日期：例如 28 日收款、29 日退款，选 29 日只计入退款，导出也只含当日退换货明细。选“全部日期”则包含原收款及后续退款。取消订单可查到，但不增加收入。

原有“状态”字段对应明细导出状态；新增“订单当前状态”按退换货结果反映已全额退款、已部分退货或已换货。

## 网页版

本次只修改前端查询，无需重新配置收钱吧或重新部署云端。完成待确认收退款、结账或挂起当前购物车后，在原浏览器刷新 http://localhost:5173/ 即可加载新界面。不要为了更新而清空浏览器数据、换端口或使用无痕窗口。

## Windows

新版位于同级 cashier-release-0.7.9/windows 文件夹：

- 安装版：摆摊收银台 Setup 0.7.9.exe。
- 便携版：摆摊收银台 0.7.9.exe。

升级前完成待处理交易并导出经营备份，退出旧软件。同一系统账户更新后，先核对原商品、流水和商户信息。网页与桌面版的经营数据不自动共享；换电脑仍需迁移经营备份及加密连接配置。

## Mac

cashier-system-0.7.9-mac-source.zip 为同步源码构建包，不是已生成的 Mac 安装包，本次未在 Mac 真机验证。

解压后，在 Mac 终端进入 cashier-system 文件夹，准备 Node.js 24 或更新版本，执行 `bash build-mac.command`。脚本安装依赖、测试并构建，成功后从 release 文件夹安装生成的 DMG。升级与换机同样先备份，再核对库存和商户配置。

## 数据保护

本次不修改历史订单、库存、赠品规则、优惠券、抽奖概率或收钱吧密钥。小程序不需要因本次流水查询更新而重新提交审核。抽奖活动时间和奖品规则仍按原云端配置生效，本次没有延长或重开活动。
