## 调整概率或名额

1. 进入底部“抽奖”，核对活动编号和当前数据。
2. 填写调整原因，勾选确认，点击“暂停新抽奖”。暂停不作废已有奖品。
3. 选择“按剩余名额”或“固定概率”，修改各奖品总名额；固定概率需合计 100%，最多两位小数。
4. 若增加总名额超过“券发放上限”，先点该奖品上限旁的图标，填写新上限及原因。成功后再修改抽奖总名额。提高券上限不会直接增加抽奖名额，也不会额外发券。
5. 填写原因、勾选确认，点击“保存配置”。保存后仍暂停，请再核对一次。
6. 再次填写原因、勾选确认，点击“恢复新抽奖”。

配置改动只影响后续抽奖。已经抽中的奖品不重抽，总名额不得小于已抽中数量。多人同时调整时，版本冲突会要求刷新，不覆盖别人刚保存的配置。断网或失败后先刷新核对，不要反复随意改数。

固定概率是每次抽奖的概率，不保证短时间内中奖数量严格按比例分布。只要任何概率大于 0 的奖品名额耗尽，所有新抽奖都会被阻止，不自动把概率分给其他奖品。暂停后补充名额，或将耗尽奖品设为 0% 并调整其他概率至总计 100%，保存核对后恢复。

“按剩余名额”会依据当前剩余奖品数量计算下一次抽奖概率。两种模式均不增加“未中奖”档位。

## 四个数量的区别

- 总名额：这项奖品最多允许多少人抽中，包含已经抽中的人数。
- 剩余：总名额减去已抽中，不是仓库库存。
- 券发放上限：券中心最多能发多少张对应权益，需要覆盖抽奖名额。
- 商品库存：在“商品”页维护的实物数量，仍在最终核销出库时扣减。

“券中心已核销”仅统计已经进入券中心并完成核销的权益，不等同于旧版小程序历史独立领取记录。调整记录显示最近 30 次奖池调整；云端保留完整记录。

## Windows、Mac 和其他电脑

### 网页版

本机继续双击桌面“启动收银网页版”，保持启动窗口打开，使用原浏览器访问 http://localhost:5173/。地址中的 localhost 指当前这台电脑，不是所有电脑共享的地址。

### Windows 软件

在发行目录的 windows 文件夹中选择“摆摊收银台 Setup 0.7.6.exe”安装，或使用“摆摊收银台 0.7.6.exe”便携版。先退出旧软件，再打开新版。旧快捷方式不一定指向新版。

### Mac 软件

本次交付 cashier-system-0.7.6-mac-source.zip，为源码构建包，不是已生成的 DMG：

1. 将 ZIP 发到 Mac，解压到固定文件夹。
2. 安装 Node.js 24 LTS 或更新版本。
3. 打开“终端”，输入 `cd `，将解压后的 cashier-system 文件夹拖入终端，按回车。
4. 输入 `bash build-mac.command` 并回车，等待安装依赖、测试和打包完成。
5. 构建成功后，在自动打开的 release 文件夹中打开 DMG，安装到“应用程序”。

尚未做 Mac 真机运行、USB 扫码及系统通知验收。软件未做 Apple 公证，如系统拒绝打开，请交由维护人员检查来源及构建结果，不要关闭整机安全保护。

### 抽奖连接的迁移

1. 在已连接的原网页版进入“抽奖 → 云端连接”。
2. 设置至少 12 位的连接包密码，点击“导出连接”。
3. 在新电脑或 Windows/Mac 软件的同一入口，输入该密码并“导入连接”。密钥会加密传输，不包含在公开安装包中。
4. 核对活动编号、名额和已抽中数字。多个管理员连接同一云端奖池，调整结果共享。

抽奖连接包不包含商品、收银订单、库存、收钱吧密钥或券核销连接。这些仍按原完整经营备份和加密支付凭证的迁移流程分别恢复，完成待处理收退款后再交接。网页和桌面经营数据不会自动共享；不能把同一库存备份复制到多台机器同时营业。
