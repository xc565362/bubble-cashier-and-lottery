# 摆摊收银台 0.7.3

本版已合并小程序中奖立减券和实物奖品的收银端功能；正式云端对接仍待服务器权限、原活动配置核对与部署，不能现在就视为已经上线。

## 本机使用

本机网页继续使用原桌面“启动收银网页版”快捷方式，或源码目录中的 `start-web.cmd`。访问 http://localhost:5173/，使用原来保存商品和订单的浏览器，不要清除浏览器数据。当前未自动启动正式支付服务，请手动打开启动窗口并保持运行。

不需要把商品导入到交付包的5194页面。原收钱吧配置没有替换。

## 正式接通后的收银

1. 立减券：先加入购买商品，再扫描小程序券码；确认抵扣金额后按原收钱吧流程收款。支付成功或全额抵扣后的零元结算成功，券才正式核销。
2. 实物奖品：先在券管理确认四种实物商品绑定。扫码自动加入对应的一件免费赠品；仅领奖选择“零元结算”，混合购买时只收售卖品金额。
3. 只有显示“实物奖品已核销，订单及库存已保存，可发放”或“收款及奖品核销已完成，可发放实物奖品”才交付实物。
4. 断网、待核对或领取确认待同步时，不要重复收款或直接发货。保持联网并执行核对，恢复原订单。
5. 每单只能使用一份抽奖奖品或优惠券。退款不恢复券和奖品资格。

## Windows 和 Mac

- Windows 新版安装包使用原应用标识及数据目录，但网页版与桌面版数据不是同一份；首次切换必须按原交接说明迁移经营备份和收钱吧加密配置。
- Mac 提供同版源码包，需在 Mac 安装 Node.js 24 或以上，解压后执行 `build-mac.command` 生成安装包。Windows 上没有生成或验证 Mac DMG。
- 更换电脑前先完成所有待核实支付、退款与券核销，导出完整经营备份和收钱吧加密配置。券中心连接与实物商品绑定需要在目标电脑另行核对配置；普通经营备份不携带券中心管理密钥。
- 不要同时用两台电脑的独立本地库存收银。

完整上线步骤见 `docs/抽奖联动部署交接-0.7.3.md`。
