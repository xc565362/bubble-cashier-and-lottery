# 摆摊收银台 0.7.2

更新日期：2026-09-20。

## 本次更新

「收银、商品、流水、赠品、券管理」五个入口在网页、Windows 和 Mac 共用的界面中统一固定在窗口底部，不再因屏幕变宽而改成随内容停靠。

- 页面按导航实际高度预留底部空间，最后一行内容可完整滚动出来。
- 窄屏采用图标在上、文字在下的布局；支持手机底部和横屏侧边安全区域。
- 窗口缩放、横竖屏变化、文字放大后会重新计算留白；购物车和提示消息相应避让导航。
- 收款等确认弹窗仍盖在导航之上，避免绕过未完成操作。
- 桌面程序启动尺寸不超过屏幕可用区域，并允许缩小到更低的窗口高度。

## 使用新版

网页版仍是 http://localhost:5173/ 。刷新原来的浏览器页面即可更新界面。重启电脑后，双击桌面的「启动收银网页版」。不要打开独立测试端口，也不要同时启动多个支付服务。

Windows：先结束待核实交易并退出旧程序，再打开 `windows/摆摊收银台 0.7.2.exe`；需要安装时使用 `windows/摆摊收银台 Setup 0.7.2.exe`。程序未做商业代码签名。更新软件不会删除原数据，也不会自动导入商户配置。

Mac：`cashier-system-0.7.2-mac-source.zip` 是源码包，不是已生成的 DMG。安装 Node.js 24，解压后在终端进入 `cashier-system` 文件夹，执行 `bash build-mac.command`，在 Mac 本机生成安装包。本次没有 Mac、iPhone 或 Android 实机验收。

保留 `cashier-system-sqb` 开发源码，后续修改仍然需要。发行包不含商品订单、商户私钥或券凭证。券后台接口未改动，随包的 `券管理与小程序接入-0.7.0.md` 仍然适用。

## 收钱吧正式配置仍然单独迁移

本次只改导航和窗口布局，没有更换任何商户配置。网页版已有正式参数：appid `28lp467052479`、品牌 `30031`、门店 `lbls1122`、网关 `https://vapi.shouqianba.com`。原有签名私钥和验签公钥沿用，无需重新生成密钥。

之前 Windows 的自动配置未成功，原桌面配置仍为测试商户；如果你还没有手动导入正式配置，不能直接拿它做正式营业收款。

1. 在原网页版进入「商品 → 收钱吧设置」，确认顶部为「正式商户参数」，appid 是 `28lp467052479`。
2. 在「加密配置迁移」自己设置 12 至 200 字符的密码，两次输入一致，点击「导出加密配置」。配置包和密码分开保管。
3. 在新版 Windows 或 Mac 的同一设置页面输入该密码，点击「导入加密配置」，选择导出的 `收钱吧加密配置.sqb.json` 并确认。
4. 替换原收银机或从网页迁到桌面时，核对正式账号、品牌、门店及原收银机编号，保持原编号不变；先导入原加密配置，再恢复经营备份。签名备份和历史订单退款都校验原终端身份，恢复后也不要随意改编号。旧端应停止收银。
5. 新增一台并行收银机是另一种场景：需独立终端编号及本地账本，不能照搬历史订单后改编号并假定可跨机退款。商品、库存、订单不会自动共享。经营数据、商户凭证、云端券数据库也须分别保管。
6. 点击「联网检测（不扣款）」。通过后，由你本人进行小额收款和退款，核实正确的收款商户、收钱吧流水、实际结算账户及库存。完整步骤见《收银系统使用与交接手册-0.7.2》。

网络检测曾出现公网 IP 获取超时；营业前再次检测，失败时检查网络或换手机热点。付款结果待核实时先查原单，不能重复发起扣款。本次界面验证没有执行真实收款、退款或联网查单。
