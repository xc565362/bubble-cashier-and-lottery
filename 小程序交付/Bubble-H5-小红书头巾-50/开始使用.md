# 山野有约 · 关注抽头巾

2026-10-08 更新：已完成与收银台 0.7.12 的本地联动。活动配置可在收银「抽奖 → 山野有约 · 关注抽头巾」维护，新中奖凭证在收银台零元核销；正式服务仍需配置和部署。

Bubble 越野赛事现场关注活动，沿用上一版 H5 的品牌识别，改为浅水蓝与白色、单品主视觉和更舒展的排版。

## 你确定的规则

- 工作人员先确认用户已关注小红书，再引导扫码进入。
- 奖品是魔术头巾，共 200 份，每次中奖领取 1 条。
- 有库存时每次抽奖的中奖概率为 50%，也可能未中奖；200 份抽完后停止。
- 活动时间暂未确定，页面显示「时间待公布」。

本版沿用每个微信账号一次机会。中奖与未中奖都保存；重新扫码、刷新、重复提交不会产生第二次抽奖。50% 是每次有效抽取的概率，并不承诺前 400 人恰好发完 200 份。

## 本机预览

双击 `启动本地预览.cmd`，在这台电脑打开 http://127.0.0.1:5190/ 。也可以在本目录执行 `npm start`。需要 Node.js 20 或以上；此电脑已可运行，无需安装前端依赖。

首页已模拟拿到工作人员确认后的参与码，可直接体验自然抽取。页面下方「演示设置」可以查看中奖、未中奖、已核销、过期、无库存和断网等状态，也可以重置本机演示。

预览核销步骤：

1. 抽中后在「我的结果」复制领取码，或在演示设置选「中奖 · 待领取」。
2. 打开「活动说明」底部的「工作人员入口」。
3. 粘贴领取码、查询、确认核销，再回「我的结果」查看已核销状态。
4. 工作台还可以体验「确认已关注，生成参与码」，点击其下方本机模拟入口返回抽奖页。

**这是隔离演示，不能实际领取头巾，不能将本机地址或演示二维码用于现场。** 演示数据只保存在当前标签页；演示重置不影响任何正式数据。头巾图为示意，实际款式待现场确认。

## 正式现场流程

工作人员核实小红书关注 → 在工作台生成一张一次性参与小程序码 → 顾客微信扫码进入 → 抽奖 → 中奖显示领取二维码/条形码 → 工作人员查询并核销 → 发放 1 条头巾。

正式参与码最多 10 分钟有效，使用一次后失效。工作人员权限、抽奖结果、库存和核销均由服务器决定，页面不会自行验证小红书关注情况。

本活动使用独立中奖记录与抽奖名额，可以与原抽奖并存。接入收银后的新中奖凭证通过同一券中心发放，在收银台扫描后免费入单，完成零元结算再发放实物并扣减本机商品库存；H5 约每 3 秒同步领奖状态。旧版未接入收银的历史凭证仍在原工作人员页面核销，不转换或重复发券。

首页和规则约每 10 秒读取活动配置。单奖品的名称、HTTPS 图片、绑定商品、中奖概率、总名额与日期可以在收银管理页调整；已中奖用户保留中奖时的原奖品。默认仍为 200 份、50%，正式日期未确定时保持暂停。

完整联动演示请到收银源码目录运行「启动头巾收银联动演示.cmd」，打开 http://127.0.0.1:5209/ 。上面的 5190 仍是独立前端演示，两者数据不互通。

## 上线还需要完成

1. 确定抽奖开始、结束和领取截止时间；确认要关注的小红书账号及工作人员名单。
2. 配置 HTTPS 网页域名和后台服务，创建本活动独立库存与记录集合。
3. 将 `public/runtime-config.js` 的 `apiBase` 指向测试通过的网关，执行 `npm run build`，部署 `dist/`。
4. 按 `integrations/接入说明.md` 将 `pages/scarf-h5/index` 接入维护中的小程序源码。参与码由后台生成并指向该原生页。
5. 部署支持动态实物奖品的券中心，在头巾后端配置对应身份和管理凭证；收银「券管理」连接同一中心，再配置独立的头巾管理接口。
6. 在收银中绑定真实库存商品、核对中奖概率/配额/日期，完成微信真机登录、扫码、两名员工并发核销验证后，再启用活动。

具体参数见 `server/后端接入与上线边界.md`。目前网关默认关闭、活动日期为空；本次没有发布网页、小程序或云函数，没有初始化真实库存。

## 工程与验证

- `public/`：网页、头巾示意图和活动配置。
- `server/`：登录、一次性参与码、50% 抽奖、库存和核销后端。
- `integrations/`：小程序扫码进入 H5 的宿主页。
- `tests/`：前端、网关与抽奖管理的本地自动化回归检查；跨项目收银核销测试在收银项目 `tests/scarf-cashier-integration.test.js`。
- `output/`：浏览器验收截图。

运行 `npm test` 进行本地检查，`npm run build` 生成正式静态文件。正式构建不包含 `preview.mjs`，配置缺失时也不会回退为演示发奖。云函数生产依赖需要在该函数目录单独安装。
