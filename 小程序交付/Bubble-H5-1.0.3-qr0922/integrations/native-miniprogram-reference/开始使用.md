# 小程序二维码版

状态：源码修改及隔离本地验证已完成，尚未上传、审核或正式发布。此目录不含旧版云函数，不会部署或覆盖云端代码。

## 本次修改

- “我的奖品”默认展示二维码；支持切换条形码，保留复制券号。
- 二维码直接包含原券号，不添加 `bubble:` 前缀、网址或其他字符。不会重新发券或改变历史券号。
- 立减券和实物奖品都支持两种显示方式。使用中、已核销、过期、作废、待同步等非可用状态不显示可扫描的码。
- 状态读取失败时暂时隐藏原码，恢复联网刷新后再显示服务端确认的状态。
- 收银端无需为二维码额外改造，仍使用原来的券查询、抵扣、占用和核销流程。实物兑奖开放时间仍由原云端配置控制，本次前端修改不会提前开放。

## 安装和导入

1. 如未安装，从微信官方页面获取 Windows 或 macOS 对应的微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html 。不要用普通电脑版微信替代。
2. 打开微信开发者工具，使用拥有本小程序开发权限的微信扫码登录。
3. 点击“导入项目”，选择本文件所在目录，即包含 `project.config.json` 的目录，不要只选择里面的 `miniprogram` 文件夹。
4. 核对 AppID 为 `wx3cfec968f30fb6c1`。工程已保留原正式云环境，不需要填入收钱吧密钥或券服务器令牌。
5. 本工程仅包含前端。不要新建云环境，不上传旧的 `cloudfunctions`，不初始化奖池或导入覆盖数据库。

## 发布前验收

本工程默认连接原正式云环境。不要为了测试点击“抽奖”，这会占用真实名额。

1. 编译后进入“我的奖品”，使用已经中奖的账号检查默认二维码；开发者工具中的账号和手机实际中奖账号可能不同。
2. 点击开发者工具“预览”，用有预览权限的微信扫码打开开发版。在手机上检查二维码、条形码切换、复制券号和刷新状态。
3. 把二维码扫进电脑记事本，应得到与页面文字完全相同的原券号，不能带 `bubble:` 前缀。
4. 真实收银验收时，先向购物车加入售卖商品，再扫描立减券，核对应收金额。每单仍限一张券。仅测试抵扣时，从购物车移除券以释放占用，不要发起真实扣款。
5. 真实交易完成后再检查小程序已核销状态及重复使用拦截。电脑扫码成功不等于已经完成真实付款核销验收。

## 正式发布

1. 手机验收通过后，在开发者工具点击“上传”。版本号按后台当前版本递增，备注可填“中奖页默认二维码，保留条形码及复制券号”。
2. 登录原小程序后台的版本管理，找到这次上传的开发版本，按照平台流程提交审核；审核通过后再发布。
3. 上传、审核、发布是不同阶段，未发布前普通顾客仍使用旧版页面。
4. 发布后退出并重新打开小程序，检查“我的奖品”默认出现二维码，再用同一把扫码枪验收。
