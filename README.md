## 环境

使用 **Node.js 24** 和 npm。券中心依赖 Node 内置 SQLite；只安装 Node 20 无法运行完整收银系统。不要拆散上表的相对目录，联动测试和演示会读取两个 H5。

## 推荐：同时预览收银台和两个活动

在仓库根目录执行：

```sh
cd cashier-system-sqb
npm ci
npm run activities:preview
```

打开 http://127.0.0.1:5211/ 。该命令自动构建所需页面，使用临时隔离数据，可从顶部入口查看两个 H5；不能真实支付、发奖或核销生产凭证。退出终端进程即可结束。若端口已占用，先关闭自己启动的旧演示或通过 BUBBLE_DUAL_PORT 指定其他端口。

## 收银系统

在 cashier-system-sqb 目录：

```sh
npm test
npm run build
npm start
```

网页版默认 http://127.0.0.1:5174/ 。桌面开发使用 npm run desktop，Windows 安装包使用 npm run dist:win。浏览器版与 Electron 版各自保存数据；源码仓库不包含经营数据或收款配置。连接正式收钱吧、券中心或抽奖服务前，请恢复自己的私密配置并核对环境。

## 分别预览两个 H5

在 此刻在地 项目目录执行 npm ci、npm test、npm start，默认端口 5188。

在 山野有约 项目目录执行 npm test、npm start，默认端口 5190。两个项目均可执行 npm run build 生成 dist。正式构建默认不连接任何未配置的后台；本地预览脚本单独注入演示模式。
